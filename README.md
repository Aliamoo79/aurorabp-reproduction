# بازتولید Aurora-BP

این پوشه پیاده‌سازی تدریجی مقالهٔ Mieloszyk و همکاران، IEEE JBHI، ۲۰۲۲ است. دادهٔ خام داخل این پوشه قرار نمی‌گیرد.

## وضعیت

فیلترهای بخش II-B نوشته شده‌اند. موجودی مجموعه و استخراج موج‌ها در کولب انجام شده است. تخمین فشار با ویژگی‌های رسمی برای ویزیت بازگشت، میانگین ۲۴ساعته، و حالت بدن اجرا شده است. مقایسه با مقاله در `REPORT_SO_FAR.md` است. ویژگی استخراج‌شده از موج خودمان وارد مدل نشده است.

## اجرا در کولب

1. این پوشه را روی درایو بگذارید، جدا از ZIP داده.
2. `notebooks/01_dataset_inspection.ipynb` را در کولب باز کنید.
3. `ZIP_PATH` را به فایل ZIP روی درایو تنظیم کنید.
4. `notebooks/02_extract_waveforms.ipynb` آرشیوها را روی دیسک موقت کولب استخراج می‌کند.
5. `notebooks/02_signal_preprocessing.ipynb` پاسخ فرکانسی فیلترها را روی سیگنال ساختگی نشان می‌دهد.
6. `notebooks/03_waveform_spotcheck.ipynb` فیلتر و مقایسهٔ ضربان را فقط روی چند فایل انجام می‌دهد.
7. `notebooks/04_return_visit_bp.ipynb` تخمین فشار ویزیت بازگشت را با ویژگی‌های رسمی و Ridge می‌سازد. ویژگی استخراج‌شده از موج خودمان در این مدل نیست.
8. `notebooks/05_ambulatory_24h.ipynb` فقط میانگین ۲۴ساعته برای کل جمعیت است.
9. `notebooks/06_ambulatory_24h_subsets.ipynb` همان حساب را برای سن ≤۳۵ و نرمال جداگانه انجام می‌دهد.
10. `notebooks/07_return_posture.ipynb` انحراف معیار SBP سمعی را برای همه، خوابیده و نشسته جدا می‌کند. ترتیب بقیهٔ کار در `PLAN.md` است.
